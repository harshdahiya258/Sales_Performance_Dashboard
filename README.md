# Sales Performance Dashboard

An interactive sales analysis dashboard built in Microsoft Excel using sample sales data.

## Dashboard features

- KPI cards for total revenue, total profit, total orders, and average order value
- Revenue charts by region, product, and salesperson
- A monthly sales trend chart
- PivotTables, PivotCharts, and slicers for exploring the data

## Workbook sheets

- **Dashboard** — KPI summary and charts
- **Sales Data** — order-level records and revenue, cost, and profit calculations
- **Pivot Tables** — summaries used by the dashboard charts
- **Lookup Lists** — product categories and unit costs used by lookup formulas

## Excel skills used

VLOOKUP, Excel formulas, PivotTables, PivotCharts, slicers, and dashboard design.

## How to use

Open the workbook in Microsoft Excel. Use the slicers to filter the dashboard. After changing the sales data, select **Data → Refresh All** to refresh the PivotTables and charts.

## Data note

The workbook uses sample data for learning and portfolio demonstration. The figures do not represent actual company results.
